(007 2026-09-04 22:55) 本機曲線顯示一段時間後消失的問題是否已修復？

已驗證答案

是。Canvas 現在使用固定的 CSS 邏輯高度，並只將 DPR 套用於內部像素緩衝區，避免每秒重繪時高度重複倍增而造成記憶體膨脹、白屏或破圖。

支持細節

  • 健康指數曲線固定為 240px；Frame Delta 與訊息間隔曲線固定為 210px。
  • DPR 上限設為 2，兼顧 Retina 清晰度與長時間記憶體穩定。
  • 每次重繪使用 setTransform 重設比例，不累積 Canvas transform。
  • 本機 BROKER CONNECTED 狀態下持續輪詢 12 秒，三張曲線重繪前後皆保持 480／420／420 內部像素高度，且瀏覽器錯誤數為 0。
